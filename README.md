# SentimentPulse

A full-stack game publisher sentiment tracker. SentimentPulse scrapes Steam Reviews, Steam Forums, and Reddit community posts daily, classifies them by sentiment using NLP, extracts recurring topics, and presents AI-generated insights on a React dashboard.

---

## Features

- **Automated ingestion** — daily at 02:00 via APScheduler; also triggerable on-demand from the UI
- **Multi-source collection** — Steam Reviews API, Steam Forum scraping (BeautifulSoup), Reddit via public JSON feeds (no credentials required)
- **NLP classification** — HuggingFace `cardiffnlp/twitter-roberta-base-sentiment-latest` with VADER fallback
- **Topic extraction** — BERTopic with scikit-learn LDA fallback
- **AI summaries** — executive summary and recommended actions generated by Claude (claude-haiku-4-5-20251001)
- **React dashboard** — KPI cards, net sentiment trend chart, volume-by-source chart, sentiment donut, topic trends table, raw posts browser
- **Time period filter** — weekly / monthly / quarterly / lifetime, wired across all pages
- **SQLite by default** — drop-in PostgreSQL support via `DATABASE_URL` env var

## Quick Start

### Prerequisites
- [Docker Desktop](https://www.docker.com/products/docker-desktop/) (recommended — handles everything automatically)
- Or: Python 3.11+ and Node.js 18+ for manual setup

---

### Option A — Docker (recommended for team installs)

**1. Clone and configure**
```bash
git clone https://github.com/sallisonhome/sentimentpulse.git
cd sentimentpulse
cp .env.example .env
```

Edit `.env` and set at minimum:
```
ANTHROPIC_API_KEY=sk-ant-...       # from console.anthropic.com
PUBLISHER_NAME=Your Studio Name
```

**2. Start the app**
```bash
docker-compose up --build
```

That's it. Docker will:
- Install all Python and Node dependencies
- Run database migrations automatically
- Download NLP models on first run (~500 MB, cached for future starts)
- Start both backend and frontend

Open [http://localhost:5173](http://localhost:5173).

> **First run:** Go to **Settings** to verify your publisher and games, then trigger an ingestion manually. After that, ingestion runs automatically at 02:00 daily.

**PostgreSQL (optional):**
```bash
docker-compose --profile postgres up --build
```

---

### Option B — Manual setup (without Docker)

**1. Clone and configure**
```bash
git clone https://github.com/sallisonhome/sentimentpulse.git
cd sentimentpulse
cp .env.example .env
# Edit .env — see Environment Variables section below
```

**2. Backend**
```bash
cd backend
python -m venv .venv
source .venv/bin/activate      # Windows: .venv\Scripts\activate
pip install -r requirements.txt
alembic upgrade head
uvicorn main:app --reload
```

**3. Frontend** (separate terminal)
```bash
cd frontend
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173). The Vite proxy forwards `/api` requests to the backend automatically.

## Environment Variables

Copy `.env.example` to `.env` and fill in the values:

| Variable | Required | Description |
|---|---|---|
| `PUBLISHER_NAME` | Recommended | Publisher name used to seed the database and discover games on Steam (e.g. `Saber Interactive`) |
| `DEVELOPER_NAME` | Optional | Developer name for Steam search — useful when games are published under a third-party label |
| `ANTHROPIC_API_KEY` | Recommended | Anthropic API key for AI-generated summaries and topic humanization. Get one at [console.anthropic.com](https://console.anthropic.com/settings/keys) |
| `DATABASE_URL` | Optional | SQLAlchemy database URL. Defaults to `sqlite:///./sentimentpulse.db`. Use `postgresql://user:pass@host/db` for PostgreSQL. |

Reddit requires no credentials — the app uses Reddit's public JSON feeds directly.
The Anthropic API key is optional — if omitted, summaries and topic labels will contain placeholder text.

```
│   │   └── summary_service.py  # Claude API executive summary generation

└── frontend/

        │   └── settings/       # GameSettingsCard
        └── pages/              # DashboardPage, SummaryPage, TopicsPage,
                                #   PostsPage, SettingsPage
```

### Ingestion Pipeline (8 steps)

1. Discover publisher games via Steam Store search
2. Fetch Steam Reviews for each active game
3. Scrape Steam Forum threads for each active game
4. Fetch Reddit posts for each configured subreddit
5. Bulk-save new posts (deduplication via `UNIQUE(external_id, source)`)
6. Classify unprocessed posts with RoBERTa / VADER
7. Extract and upsert topic trends (BERTopic / LDA)
8. Generate daily summary per game (Claude API)

## API Reference

All endpoints are prefixed with `/api`.

| Method | Path | Description |
|---|---|---|
| `GET` | `/health` | Liveness probe |
| `GET` | `/api/publishers/me` | Get the configured publisher |
| `GET` | `/api/games` | List all games |
| `GET` | `/api/games/latest` | Get the most recently released game |
| `GET` | `/api/games/{id}` | Get a game with its latest daily summary |
| `PATCH` | `/api/games/{id}` | Update game settings (subreddits, is_active) |
| `GET` | `/api/games/{id}/dashboard` | Full KPI data for a time period |
| `GET` | `/api/games/{id}/summaries` | Daily summary history |
| `GET` | `/api/games/{id}/summaries/latest` | Most recent daily summary |
| `GET` | `/api/games/{id}/topics` | Topic trend records |
| `GET` | `/api/games/{id}/posts` | Paginated raw posts with filters |
| `GET` | `/api/ingest/status` | Current ingestion status |
| `POST` | `/api/ingest/run` | Trigger ingestion manually (HTTP 202) |

Interactive API docs are available at [http://localhost:8000/docs](http://localhost:8000/docs) when the backend is running.

## Database Migrations

Migrations are managed with Alembic:

```bash
cd backend

# Apply all pending migrations
alembic upgrade head

# Create a new migration after changing models.py
alembic revision --autogenerate -m "description of change"
```

> **Note:** Never change `models.py` without creating a corresponding Alembic migration.

## Development Notes

- The Vite dev server proxies `/api` and `/health` to `http://localhost:8000` — no CORS configuration needed in dev
- The default game selected in the UI is always the most recently released game (`GET /api/games/latest`)
- The period filter (weekly / monthly / quarterly / lifetime) is stored in `localStorage` and persists across page reloads
- All external API calls (Steam, Reddit, Claude, NLP model) are wrapped in `try/except` — failures are logged but never abort the ingestion pipeline
- The ingestor uses `is_running` state to prevent concurrent runs; a second `POST /api/ingest/run` while one is in progress returns `{"status": "skipped"}`
