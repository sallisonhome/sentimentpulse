Status: UNCOMMITTED proposal. No workflow dispatch or production execution authorized here.

Scope: export-buying-snapshot.py defines 17 tables and 7 setting keys. Original table
DDL, explicit indexes, rowids, row order and included sqlite_stat1 are retained.
All non-allowlisted columns are replaced with NULL or fixed constraint-safe values;
unknown required columns fail closed. No users/auth/cookies/sessions/keys, product
notes, raw store JSON or endpoint URLs are selected. steam_unit_milestones.payload_json
is retained because it is model calibration, not an authentication payload.

Runtime: original SQLite opened mode=ro, PRAGMA query_only=ON, authorizer rejects writes.
One BEGIN/read snapshot across all 17 tables; no source VACUUM/ANALYZE/backup API.
Read transaction can pin WAL during export: maximum 120 seconds, sequential 1000-row
batches, maintenance flock nonblocking, reject active daily job, nice15/idle IO.
Only destination temporary database has writes. No server restarts/deploy/polls.
1 GiB output safety bound. Existing schema-stat4 presence is recorded; stat4 is
not exported, so exact production planner parity is not assumed for stat4 builds.

Encryption: OpenSSL CMS AuthEnvelopedData AES-256-GCM, recipient RSA public cert.
Only snapshot.cms transferred from droplet to Actions/upload-artifact.
Plain data.db and manifest.json exist only in private remote temp directory and
are removed by temporary-directory cleanup; workflow trap removes remote bundle.

and files0600 limit exposure, but operator cleanup could be required afterward.
